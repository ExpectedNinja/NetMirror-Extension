### What this repository provides

| Target | How it works | Node required? |
| --- | --- | --- |
| **CloudStream** (Android) | Kotlin extension built from `Netmirror/` | No |
| **SkyStream** (Android, iOS, Windows, macOS, Linux, TV) | Native SkyStream plugin in `skystream/`, or the same `.cs3` extension | No |
| **Nuvio** (Android, iOS, TV, desktop) | Native Nuvio scraper in `nuvio/` | No |
| **Stremio** (Android, iOS, Windows, macOS, Linux, TV, Web) | Stremio addon in `addon/` | Yes, for hosting the addon |
| **Any other Stremio-compatible app** | Stremio addon in `addon/` | Yes, for hosting the addon |

The extension now uses NetMirror's current `newtv` API for Netflix, Prime Video and Hotstar. The old `verify.php` / `mobile/*` flow (and its Cloudflare challenge loop) is gone. Requests are serialised, cached and retried with backoff, so the "too many requests" error no longer appears when several providers load at once.

### CloudStream / SkyStream `.cs3`

1. Add this repository in **Settings → Extensions → Add repository**:

        https://raw.githubusercontent.com/ExpectedNinja/NetMirror-Extension/refs/heads/builds/plugins.json

   Older builds may still point at `Netflix.json`; both are generated by CI.

2. Install **NetMirror**.
3. Enable **Netflix**, **Prime Video** and **Hotstar**. Hotstar includes Disney+ content; the separate Disney provider was removed because NetMirror serves it from the same catalogue.

### SkyStream native plugin (no Node)

SkyStream can run its own JavaScript plugins directly. Add this repository URL in **Settings → Extensions → Add Repository**:

```
https://raw.githubusercontent.com/ExpectedNinja/NetMirror-Extension/master/skystream/repo.json
```

Then install **NetMirror** and enable Netflix, Prime Video and/or Hotstar from the plugin settings. The plugin runs inside SkyStream on Android, iOS, Windows, macOS, Linux and TV; no server, Node.js or Docker is involved.

### Nuvio native plugin (no Node)

Nuvio can run local JavaScript scrapers. Add this repository URL in **Settings → Content & Discovery → Plugins**:

```
https://raw.githubusercontent.com/ExpectedNinja/NetMirror-Extension/master/nuvio/
```

Enable **NetMirror**. It uses Nuvio's TMDB IDs and returns direct 1080p/720p/480p/360p streams plus subtitles. No server or Node.js is involved.

### Stremio addon

Stremio itself does not run local scrapers, so it needs an HTTP addon. The addon in `addon/` also works in Nuvio and SkyStream if you prefer that path.

#### Run locally

```bash
cd addon
npm start
```

Then add this manifest URL in your app:

```
http://<your-lan-ip>:7000/manifest.json
```

#### Docker

```bash
docker build -t netmirror-addon ./addon
docker run -p 7000:7000 netmirror-addon
```

or with Compose:

```bash
docker compose -f addon/docker-compose.yml up -d
```

#### Hosted / remote

Any Node host works (Render, Railway, Fly.io, a VPS, a NAS). Set `PUBLIC_URL` to the public address so the landing page and install links are correct:

```bash
PUBLIC_URL=https://netmirror.example.com PORT=7000 node addon/src/server.js
```

Optional environment variables:

| Variable | Purpose |
| --- | --- |
| `PORT` | HTTP port, default `7000` |
| `PUBLIC_URL` | Public base URL used on the landing page |
| `TMDB_READ_TOKEN` | Optional TMDB v3 read token. When set, IMDb IDs are resolved to TMDB IDs and streams come from NetMirror's direct `embed-tmdb` API. Without it the addon falls back to Cinemeta + NetMirror search. |
| `CATALOG_LIMIT` | Maximum items per catalog row, default `8` |

#### Addon features

- Catalogs for Netflix, Prime Video and Hotstar movies/series, plus search.
- Stream resolution from Stremio/Nuvio IDs:
  - `tt0137523` (IMDb) → Cinemeta title/year → NetMirror search → playable link.
  - `tt0944947:1:1` (series episode) → correct season/episode lookup.
  - `tmdb:550` → NetMirror `embed-tmdb` direct streams (1080p/720p/480p/360p where available).
  - `netmirror:nf:26004747` → direct NetMirror content/episode ID.
- HLS and MP4 links include the required `Referer` and player `User-Agent` through `headers` and `behaviorHints.proxyHeaders`.
- Shared request queue (250 ms gap, 3 concurrent), in-memory TTL cache and 429/5xx retry with exponential backoff.

### Repository layout

```
Netmirror/                 CloudStream/SkyStream Kotlin extension
  src/main/kotlin/...      NewTvApi.kt (shared rate-limited client) + providers
skystream/                 Native SkyStream plugin repo (no Node)
  netmirror/plugin.js      getHome / search / load / loadStreams
  dist/                    packaged .sky + plugins.json
nuvio/                     Native Nuvio scraper (no Node)
  providers/netmirror.js   getStreams(tmdbId, mediaType, season, episode)
addon/                     Stremio/Nuvio/SkyStream HTTP addon (Node.js)
  src/core.js              NetMirror client, cache, retry, ID resolution
  src/server.js            Stremio addon HTTP routes
.github/workflows/         CloudStream build + addon image
```
